# SyncFlow

### Enterprise Business Integration & Automation Platform

SyncFlow is a centralized business integration and automation
platform designed to connect ecommerce, ERP, CRM, and supplier
systems through reliable data synchronization and workflow
automation.

## Technology Stack

### Backend
- PHP 8.3
- Symfony 7.4 LTS
- Doctrine ORM
- PostgreSQL

### Infrastructure
- Redis
- Symfony Messenger
- Docker
- Nginx

### Frontend
- React
- TypeScript

### Automation
- Node.js
- Playwright

### Testing
- PHPUnit
- Playwright

## Core Features

- Integration Management
- Customer Synchronization
- Product Synchronization
- Order Synchronization
- Inventory Management
- Workflow Automation
- Asynchronous Processing
- API Integration
- AI Product Enrichment
- Browser Automation
- Monitoring & Error Management

## Architecture

The project follows a Modular Monolith architecture
with asynchronous processing and independent integration
adapters.
